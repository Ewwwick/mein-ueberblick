# Mein Überblick

Dein Schul-Überblick für Windows im iOS-Look (Liquid Glass): Kalender, Hausaufgaben, Klassenarbeiten mit Lernplan, Noten, Stundenplan, Notizen, Fokus-Timer, Countdowns und Wetter. Hausaufgaben und Klassenarbeiten landen auf Wunsch automatisch im Apple-Kalender (iPhone).

## Installieren

1. Oben auf **Code → Download ZIP** klicken und die ZIP entpacken (Rechtsklick → „Alle extrahieren“).
2. **Python** installieren (Microsoft Store → „Python 3.13“).
3. Im Ordner `1_installieren.bat` und danach `2_starten.bat` doppelklicken.

Alles Weitere steht in der `ANLEITUNG.txt`.

## Updates

Die App sucht selbst nach neuen Versionen und zeigt dann unten „Update verfügbar – Jetzt installieren“. Deine eigenen Daten (Ordner `daten`) bleiben dabei immer erhalten.
